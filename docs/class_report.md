## 1. 왜 만드나
- 수업 안 수행평가 결과가 세특에만 쓰이고, 다음 수업·학생 지도로 돌아오는 화면이 없다(올립 09-30, VOC `../clipo_voc/archive/func_all.txt`).
- 처음 니즈 세 가지: 평가 기본 통계 · 지난 평가보다 오르내린 학생(피드백 터치포인트) · 평균이 낮은 채점 요소(다음 수업·평가 준비).
- 참고: EssayGrader 벤치마킹 노션 §5-11(과제 단위 Metrics). 8월 결론("사실 집계까지만, 학생 지목·판정 배지 제외")을 올립이 "점수 변화 목록은 넣고 판정·처방은 뺀다"로 고쳤다.

## 2. 올립이 확정한 규칙 (2026-09-30) — 다시 묻지 않는다
1. **한 평가 × 한 반은 채점 탭, 반과 평가를 가로지르는 비교는 리포트 탭.**
2. **점수 비교는 100점 환산 점수.** `득점률`·`%p`는 쓰지 않는다(낯선 눈 점검에서 "점수가 17% 올랐다"로 잘못 읽힘).
3. **결과 보기는 실시간, 비교·학생 지목·AI는 마감 후.** 마감 전 평가는 점수를 저장한 학생만 집계하고, AI 점수만 있는 학생은 뺀다. 저장한 점수가 없는 반은 `-`.
4. **학생 개인에게 판정 배지·처방 문장 없음 — 사실만.** 오르내린 학생은 `학생 65 → 83점 / 반 평균 67 → 70점`처럼 두 사실만. 학급 단위 제안은 AI 분석 의견으로 허용.
5. **AI는 평가 단위 `AI 분석 의견` 하나.** `AI 분석 실행` 버튼 · 마감한 평가만 · 실행당 차감. 나머지는 모두 계산이라 크레딧 없음.

## 4. 리포트 탭 — `class_report_v2_260930.html`
**화면**
- `평가별 결과` 카드: 카드 안 드롭다운으로 평가 하나(기본 = 최근 마감). 요약(통계·분포·학급별 표) → `AI 분석 의견` 상자 → 채점 요소별 점수(막대는 N개 학급 평균에만, 학급 칸은 숫자만 — 반이 10개일 수 있음. 가장 낮은 요소는 펼쳐 둠).
- `평가별 흐름` 카드: 드롭다운과 무관하게 마감한 평가 최근 5개. 학급마다 작은 선 차트 + `차트｜표`. `지난 평가보다 오르내린 학생` = 반 평균보다 10점 이상 더 오르내린 학생, 줄마다 평가별 작은 막대.
- 말 한 벌: `최근 평가`·`지난 평가`·`오른`·`내려간`, `전체` 대신 `N개 학급`.

**AI 분석 의견** — 성취기준에 이어 붙인 지도·평가 제안
- 재료 = 점수(요소별·학급별·점수 구간) · 채점기준 문장 · 이 평가의 성취기준. **답안·채점 근거는 읽지 않는다.**
- 짜임 = 한 줄 결론 → `이 평가의 성취기준`(평가 단위로 한 번, 점수가 낮았던 대목에 밑줄) → `다시 짚어 줄 개념`(약한 요소마다 "성취기준 [코드]의 ‘대목’에 해당해요" + "39명 가운데 27명이 ‘채점기준 문장’ 수준" + 개념) → `다음 평가 구성 제안` → `따로 챙길 반`(짚을 것이 있는 반만, 없으면 묶음 자체를 내지 않음).
- ⚠ 제품에 채점 요소↔성취기준 연결 정보가 없고 교사도 "다 관련 있다"고 할 것 → 요소를 성취기준별로 나눠 담지 않고 AI의 해석으로 잇는다(해석임을 밝힘).
- 올립이 뺀 것: 답안 쓰는 요령 · 답안 발췌 · 학생 이름 · 많이 놓친 점 · 수업 흐름 제안 · "근거 53점" 같은 줄임.
- 디자인 = 옅은 파랑 상자 + 아이콘 타일 + 흰 본문. 목업의 글은 평가 4개마다 손으로 쓴 예시(`OPINION`)이고 숫자만 계산.
- 성취기준 문구 = 2022 개정 중학교 국어(9국02·9국03), 2차 자료에서 가져와 **고시 원문 대조 필요.**

**해시**: `#report` · `#report-ai`(분석 의견 실행 뒤) · `#report-e3`·`#report-a`·`#report-e1`(그 평가를 고름) · `#report-p`(마감 전) · `#first`(마감 1개) · `#pending-only` · `#empty`

## 5. 학급 채점 현황 리뉴얼 — `class_scoring_detail_v4_260930.html`
개발 확정본 `class_scoring_detail_v3_260623.html`을 복제하고 델타만 얹었다. **기존 기능은 전부 유지**(정렬 · 초기화 · 점수 일괄 수정 · 상세 보기 · 채점 결과 다운로드 · AI 채점 실행 창 · 결과 공개 창).

**화면 순서**: 머리말 → `채점 진행` 카드 → `채점 결과 요약` 카드 → 학생 표

| 자리 | 내용 |
|---|---|
| `채점 진행` 카드 | 3단계 카드 3장을 카드 하나로. 단계마다 윗줄 = 번호 · 이름 · 지금 상태(`7명 채점됨 · 1명 채점 중 · 2명 실패` 등, 없으면 `아직 채점 전이에요`), 아랫줄 = 주 버튼 + 곁가지 **테두리 버튼**. 끝난 단계는 체크, 파란 채움은 지금 할 단계 하나만 |
| 1단계 버튼 | AI 채점을 한 번이라도 실행했으면 `AI 채점 다시 하기`(재실행 창), 아니면 `AI 채점 시작하기`. 곁가지 `AI 채점 결과`는 AI 채점된 학생이 있을 때만 |
| 3단계 곁가지 | `채점 결과 다운로드` — 다운로드도 결과를 쓰는 일이라 공개와 같은 단계(머리말의 초록 버튼은 없앰) |
| `채점 결과 요약` | **선생님이 저장한 최종 점수 기준**, 접지 않고 늘 펼침. "점수를 저장한 N명 기준" · 반 평균·최고·최저 · 총점 분포. 오른쪽 위 `채점 요소별 점수` → 페이지 |
| `채점 요소별 점수` 페이지(`#result`) | 최종 점수 기준 분석. `눈에 띄는 점` + 요소마다 100점 환산 막대 · "N명 가운데 M명이 4~7점 구간에 몰려 있어요" · 점수 구간별 표(채점기준 · 학생 수 · `가장 많음` · 학생 이름과 그 요소 점수). 문장은 점수에서 계산한 사실(AI 호출·크레딧 없음) |
| `AI 채점 결과` 팝업(`#ai`) | **제품 화면 그대로**의 `AI 채점 결과 확인`(§6). 델타 하나 = **막대에 마우스를 올리면 그 점수를 받은 학생 이름이 말풍선으로**(올립 09-30) |
| 표 머리 | 정렬 · `초기화` · `점수 일괄 수정`(→ 페이지 `#edit`, §6). 학생 표 열은 v3 그대로 |

**해시**: 케이스 = `#before`(AI 채점 전) · 기본(채점 진행 중) · `#done`(점수 저장을 마친 뒤). 각각 뒤에 `-ai`(팝업) · `-result`(채점 요소별 점수) · `-edit`(점수 일괄 수정). 기본 케이스는 `#ai` · `#result` · `#edit`. 리포트 탭의 `채점 탭에서 보기`가 `#done`으로 온다.

**넣지 않은 것**: 오르내린 학생(리포트 탭에 있음) · AI 분석 의견(평가 단위) · 보기 스위치(요소별 점수 보기·피드백 함께 보기 — 복잡도만 늘려 뺌).

## 6. 실제 제품에서 확인한 사실 (2026-09-30, clipo.ai 테스트 계정)
- **`AI 채점 결과`** = 표 머리 버튼 → `AI 채점 결과 확인` 팝업. 참고용 초안 안내 → `채점 결과 요약`(전체 · AI 채점 성공 · AI 채점 실패) → "※ 미채점 학생의 채점 결과는 점수 분포에 반영되지 않습니다." → `총점 점수 분포` → `채점 요소별 점수 분포`(요소마다 카드). 막대 = 그 점수를 받은 학생 수, 가로축은 실제로 나온 점수만, 카드마다 `평균 N점` 배지. **분석 문장은 없다.**
- **`점수 일괄 수정`** = 창이 아니라 **페이지**(`…/scorings/<평가>/<반>/result`). **마감된 평가에서는 버튼이 꺼진다.** 제목 `1학년 1반 점수 일괄 수정` · 안내 상자(`AI 채점을 실행해야 세특 초안에 과제물 내용이 반영됩니다.` + `확인했습니다.`) · `채점 결과` 카드(`학급 점수 분포` · `엑셀 일괄 업로드`) · 표(학년·반·번호·이름·총점·채점 요소별 최종 점수·행마다 `점수 수정`).
- 제품의 3단계 카드 문구·버튼은 v3 목업과 같다. 머리말 오른쪽에 `채점 결과 다운로드`.
- ⚠ **아직 못 본 것**: 점수 일괄 수정 페이지에서 행의 `점수 수정` · `학급 점수 분포` · `엑셀 일괄 업로드`를 눌렀을 때의 화면, 안내 상자 색(목업의 주황은 임의). v4에서는 토스트만 뜬다.
- 크롬 확장(Claude in Chrome)이 이 사이트에서 클릭·스크린샷을 자주 막는다(`Cannot access a chrome-extension:// URL of different extension`). 글 읽기와 주소 이동은 된다 → 눌러야 보이는 화면은 올립에게 스크린샷을 받는다.

## 7. 올립 피드백 모음 — 방향을 잡을 때
- 요약은 토글 뒤에 숨기지 말 것. 큰 버튼 카드는 줄이고, 디테일은 다른 페이지로.
- 버튼엔 맥락(지금 상태)을 붙인다. 글자 버튼보다 테두리 버튼.
- **AI 채점 결과와 선생님의 실제 채점 결과는 다른 것.** AI 채점 결과는 제품의 차트 팝업 그대로 두고, 분석은 최종 점수 쪽에만.
- 막대 차트만 보여 주지 말고 "어느 채점기준에 몰렸나 · 학생 누가 몇 점".
- 복잡도만 늘리는 보기 옵션은 뺀다. `초기화`·`점수 일괄 수정`은 버튼으로 둔다.
- 리포트 탭: 표보다 차트, 학생 단위 숫자 나열은 가독성이 떨어짐, 레이블은 쉬운 말로.
