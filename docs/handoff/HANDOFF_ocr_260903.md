### 지킬 것 4가지 — 처리한 방식
1. **좌측 원본(쪽 넘김·확대)** — 팝업 전용 상태(`_ocrmPage/_ocrmZoom/_ocrmRot`)로 분리. 뒤 화면 뷰어를 건드리지 않으므로 옛 `switchViewer('orig')` 호출은 뺐다.
2. **크레딧 확인을 팝업 안에서 끝냄** — 체크박스를 켜면 푸터에 `AI 크레딧 1개가 차감돼요. (지금 842개)`가 뜨고, `결과 저장`이 곧 실행이다. **다시 채점 설정 모달을 거치지 않고 `doRerunAi('overwrite')`를 직접 부른다**(채점 강도는 마지막 저장값). 옛 `saveAndRerunAi`→`rerunAi`(설정 모달) 경로는 팝업 위 모달이 되고 크레딧을 두 번 묻게 돼 폐기.
3. **고친 게 있으면 X에서 한 번 묻기** — 모달을 또 띄우지 않고 **푸터 위 인라인 한 줄**(`#ocrmCloseConfirm`, `계속 수정` / `저장하지 않고 닫기`). `저장하지 않고 닫기`는 스냅샷으로 되돌린 뒤 닫는다.
4. **그대로 둔 것** — 온보딩 2단계 대상 `#ocrEditBtn`(+빨간 점 `#ocrEditDot`), 맨 위 인식 불확실 안내 `#ocrReviewNotice`, `문항 N. 발문` 형식(알약 태그 없음), 인덱스 기반 데이터 `ocrd-body-N`.

### 바뀐 편집 방식
- 클릭하면 textarea로 바뀌던 상태머신(`editSection`·`openSectionEdit`·`saveSection`·`편집 중` 배지)을 없애고 **항상 편집 가능한 칸**으로 바꿨다. 줄리 시안의 회색 칸이 곧 입력칸이고, `feedback_editable_affordance`(바탕색 가르기 + hover·focus)에 맞다. 수식 버튼은 이제 항상 보인다.
- **풀이 칸 신설**(`ocrd-solve-N`). 비어 있으면 `(미작성 · 필요 시 직접 입력)`. 값이 있는 건 문항 2뿐(기존 인식 결과 탭 데이터 이식).
- 답 칸 id는 `ocrd-body-N` 유지(옛 `ocrd-ta-N`은 없어짐 — 수식 버튼도 `ocrd-body-N`을 가리킨다).
- `확인 필요` 칩·불확실 안내는 고치면 **지우지 않고 감춘다** — 그래야 `초기 인식 결과로 되돌리기`가 산다.
- `applyTypingViewer`(직접 입력 제출 화면)가 읽던 `.rubric-ocr-body` → `.ocrq-ans`(textarea `.value`)로 교체. 발문은 `.rubric-ocr-desc` 그대로.

### 같이 고친 것
- **`.ctrl-btn` CSS가 죽어 있었다** — `.ctrl-btn{width:32px;height:32px;\1border-radius:4px}`. 옛 일괄 치환이 `\1`을 남기면서 `display:flex`부터 `cursor:pointer`까지 통째로 먹혔고 `border-radius`도 무효였다. 2파일 모두 복구. (초등·구버전 파일엔 정상값이 남아 있어 그대로 가져옴)
- **재채점 유도 모달 `#ocrRerunAskModal` 삭제** — 푸터 체크박스가 그 결정을 대신한다. 저장만 하면 우측 패널 `#ocrEditedBanner`(인식 수정 후 미재채점)가 뜬다. 배너의 `[다시 채점]`이 부르는 `ocrRerunNow()`는 남겨 뒀다(설정 모달로 연결).
