PRD V1.1 직접 채점 표·변경표 8·확인 경로·QA 13·류지안 행 갱신함.
- **보기 설정 [AI 피드백] 끔 → 섹션 접기 버그 수정**: 접기 규칙이 채점 전 학생의 `AI 채점 실행` CTA(빈 상태 안)까지 삼켜 "실행 버튼이 사라졌다"(올립). 빈 상태(`.empty-state`)가 있으면 섹션을 접지 않도록 `:has()` 가드 + 카드 피드백 블록만 숨김.

- **OCR 품질 안내(인식 불확실 주황·정확도 낮음 빨강)를 우측 채점 패널에서 제거 → 인식 결과 수정 드로워 맨 위로(올립 26-09-04 밤).** 올립 원칙 둘: ① "OCR 얘기는 OCR 화면에서만" ② "기존 채점 사용자에게 채점 결과 화면이 크게 달라지지 않게". 채점 화면에 남는 OCR 흔적은 **`인식 결과 수정` 버튼의 빨간 점(`#ocrEditDot`) 하나**(툴팁 `인식 확인이 필요해요`, 대상=인식 불확실·정확도 낮음, 직접 채점 켜면 점·안내 모두 끔). 드로워 안내는 버튼 없는 문장형(드로워가 열리면 왼쪽이 원본으로 고정되므로 `원본 보기` 버튼 불필요). 우측 패널엔 이제 재채점 유도 2종(인식 수정 후 미재채점·파일 교체)만 남음 — 점수가 옛 기준이라는 채점 얘기라서. PRD V1.1 케이스 표(인식 불확실·정확도 낮음 행)·규칙 불릿·QA 20·21 갱신. ⚠️ 26-08-28 화면 규칙 "있는데 조치 필요 케이스=우측 패널 상단 배너"는 **OCR 품질 건에 한해 폐기**.

- **직접 채점이 켜지면 인식 결과 수정도 잠금(올립 26-09-04 밤).** 인식 결과는 AI 채점에만 쓰이니 AI를 빼면 고칠 이유가 없음. 드로워 본문 문항 편집 비활성(글자 흐림·연필/수식 버튼 숨김·클릭 무시), 편집 중이던 문항은 닫음, [수정 저장]도 비활성(기존 [저장 후 AI 채점] 잠금과 함께). 맨 위 보라 안내 `직접 채점 중이라 인식 결과를 고칠 수 없어요. 위 설정을 끄면 다시 고칠 수 있어요.` 끄면 전부 복귀. PRD 직접 채점 표 '켜면' 행·Q&A·QA 14 갱신.

- **⚠️ 정책 정정 — 정확도 낮음(불확실 문항 70% 이상) = 인식 결과 미표시 + AI 채점 제외 + 직접 채점 안내(올립 26-09-04 밤, HIAI와 같은 원칙).** 26-09-03에 "정확도 낮음은 채점 실패가 아니다 — 결과 그대로 표시"로 잡았던 건 **오류였음**. 최유진(10104) = `ocrCase:'lowacc'`, 채점 상태 미채점. 좌측 인식 결과 탭 빈 상태(`인식 정확도가 너무 낮아요` + 직접 채점/다시 채점 안내, 인식 결과 수정 잠김), 우측 AI 피드백 빈 상태 `AI 채점에서 빠졌어요` + [다시 채점](인식부터 재실행). 학급 채점 현황·과제물 관리 실행 모달은 AI 결과 `-`·미채점·`정확도 낮음` 태그. `applyLowAccUI`·36/18점 경로·드로워 정확도 낮음 안내·진입점 점 조건에서 lowAcc 제거. PRD V1.1 상태 표·케이스 표·Q&A·QA 21·류지안 옆 최유진 행 갱신. HIAI 화면은 **참고만**(카피·배치는 CLIPO 빈 상태 카드 패턴).
- **자동저장 표시 제거(올립 26-09-04).** CLIPO는 자동저장이 없는데 인라인 수정 드로워의 문항 편집 닫힘 때 `✓ 저장됨` 배지+토스트, 피드백 블록·선생님 피드백 blur 때 `저장했어요` 토스트가 떴음(HIAI 이식 잔재). 전부 제거 — 저장은 [수정 저장]·[저장 후 다음] 버튼으로만. 확인 필요 표시 해제 토스트만 남김.

- **⚠️ 재정정 — `정확도 낮음` 케이스 자체를 삭제(올립 26-09-04 밤, 최종).** 바로 위 "미표시+AI 제외" 정정을 한 시간 만에 뒤집음. 이유: CLIPO는 크레딧을 차감하고 반환하지 않으므로 결과를 감출 수 없음 — 불확실 문항이 많아도 인식 결과·점수 그대로 노출 + 문항별 확인 필요 표시만(=인식 불확실 케이스로 흡수). 70% 임계값·별도 안내 없음. **HIAI와 의도적으로 다른 지점**(HIAI는 미표시·제외·반환). 최유진(10104)을 오세진 전례대로 **전 명단에서 삭제**(채점 상세 3·학급 채점 현황 STUDENTS/RUN·과제물 관리 6곳) → 14명. CASE_UI.lowacc 제거. PRD V1.1: 케이스 표 행·Q&A·QA 21(이후 21~25로 재번호)·⚙️ 3종·학생별 케이스 행 삭제, 규칙 불릿에 "정확도 낮음 케이스 없음 + HIAI와 다른 이유" 추가.

- **⚠️ 직접 채점(AI 제외) 기능 전체 삭제(올립 26-09-04 밤, 최종).** 하루 종일 자리를 옮기다 결론: 점수 고르고 저장하면 그게 직접 채점이고, AI 채점은 실행 모달에서 고른 학생만 돌며 채점 완료 학생은 기본 해제되므로 상태를 따로 둘 이유가 없음(HIAI에서 온 개념, CLIPO는 실행이 명시적 선택). 제거한 것: 드로워 헤더 스위치·잠금 안내·`self-grade` 잠금 CSS/JS·`clipo_ocr_exclude` sessionStorage·재채점 가드·초등 배너·학급 채점 현황/과제물 관리의 `직접 채점 · 해제` 링크와 제외 규칙(채점 불가 = 미제출뿐). 류지안(10116)은 오세진·최유진처럼 **전 명단에서 삭제 → 13명**. 남긴 것: `인식 결과 수정` 버튼의 확인 필요 점(`applyOcrDot`, 인식 불확실만). PRD V1.1: 변경표 8행·직접 채점 표·크레딧 표 행·Q&A("AI 없이 직접 채점하려면 → 별도 설정 없음")·확인 경로·QA 13~15(→13 하나로, 이후 14~23 재번호)·류지안 행 삭제, 비범위에 "직접 채점 지정 상태" 행 추가. ⚠️ **다시 넣자고 제안 금지.**
