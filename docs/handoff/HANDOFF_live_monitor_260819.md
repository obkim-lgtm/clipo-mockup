> 목업의 색·간격·타이포는 기존 화면에서 끌어다 쓴 임시값이니 스펙으로 읽지 말 것.

## 왜 만드나

작성 과정 기록(v2)은 **제출된 뒤에 여는 사후 확인**이라, 수업 중에 문제를 잡아
개입할 수가 없다. 같은 신호를 **아직 끝나지 않은 상태**로 보여주는 화면이 필요하다.

- 시안: `output/focus_log_v3_260819.html#monitor`
- 배포: https://obkim-lgtm.github.io/clipo-mockup/output/focus_log_v3_260819.html#monitor
- 진입: 과제물 관리 > 학생 제출 현황 화면 우상단 `실시간 모니터링`
- 사후 로그(v2)는 그대로 두고 복제본에 얹었다. 공유 내비게이터(`mock_nav_dw.js`)는 미변경.

## 우리가 아는 것 / 모르는 것

경쟁 제품(클래스툴 등)은 학생 화면을 미러링하지만 **우리는 하지 않는다.**
대신 클래스툴에 없는 축이 하나 있다 — 글자 수가 늘고 있는지.

| | 아는가 | 비고 |
|---|---|---|
| 클리포를 벗어났는지 | ⭕ | `visibilitychange` · `blur` |
| 얼마나 썼는지 | ⭕ | 글자 수 표본 |
| 제출했는지 | ⭕ | |
| 학생 화면 내용 | ❌ | 미러링 없음 |
| 방문한 사이트 | ❌ | |
| 답안 내용 | ❌ | 실시간 화면에는 노출하지 않음 |
| 스마트폰 등 다른 기기 사용 | ❌ | 감지 불가 |

**부정행위인지는 판단하지 않는다.** 시스템은 있었던 일만 남긴다.
(v2 `작성 과정` 열 설명 팝오버와 같은 원칙 — 문구도 맞춰 쓸 것)

## 카드 상태 판정

| 상태 | 판정 규칙 *(위에서부터 먼저 걸리는 것으로 확정)* | 글자 수 | 보조 문구 | 클릭 |
|---|---|---|---|---|
| 기록 없음 | 파일 첨부 과제이거나 교사가 대신 올림 | `–` | 파일로 낸 과제예요 | 토스트 안내 |
| 다른 화면 | `visibilitychange`·`blur`가 아직 안 닫힘 | 이탈 직전 값 유지 | 3분째 | 작성 과정 팝업 |
| 기록 끊김 | 표본이 안 올라오는 중 | 끊기기 전 값 유지 | 2분째 · 원인은 알 수 없어요 | 작성 과정 팝업 |
| 제출 완료 | 제출 시각이 찍힘 | 최종 값 | 14:38 제출 | 작성 과정 팝업 |
| 미시작 | 답안 화면을 아직 안 엶 | `–` | 아직 답안 화면을 안 열었어요 | 토스트 안내 |
| 멈춤 | 글자 수가 2분 이상 그대로 | 현재 값 | 4분째 그대로 | 작성 과정 팝업 |
| 작성 중 | 위 어디에도 안 걸림 | 현재 값 | 1분 동안 +14자 *(0이면 "1분째 그대로")* | 작성 과정 팝업 |

- 배지 라벨은 상태명 그대로 쓴다.
- **`멈춤`만 글자 수 표본에서 계산해 낸 값**이고, 나머지는 시스템에 그대로 있는 상태다.
  왜 멈췄는지(고민 중·딴짓·자리 비움)는 판단하지 않는다.
- 상태 판정에 **제출 현황 표의 `제출/미제출` 값을 쓰지 않는다.** 그건 수업이 끝난 뒤의
  값이고, 수업 중에는 모두가 쓰고 있는 중이다.

## 화면 동작 규칙

| 항목 | 규칙 | 이유 |
|---|---|---|
| 카드 정렬 | **학번순 고정.** 상태가 바뀌어도 재정렬하지 않는다 | 자리가 움직이면 교사가 학생을 못 찾는다 |
| 강조 범위 | 카드째 강조하는 것은 `다른 화면` 하나뿐. 나머지는 배지로만 구분 | 강조가 여럿이면 강조가 없는 것과 같다 |
| 상단 요약 | `다른 화면 N` + `제출 N / 전체` **둘만.** 상태 7종을 다 세지 않는다 | 상태 이름은 카드에 이미 있고, 여러 숫자가 동시에 바뀌면 눈이 붙을 곳이 없다 |
| `다른 화면` 요약 | 0명이면 무채색, 1명부터 색이 든다 | 평소엔 조용하고 개입할 때만 걸리게 |
| 시계 | 현재 시각 + `마감 HH:MM · N분 남음` | **교시·수업 길이는 시스템이 모른다.** 과제가 아는 건 마감 시각뿐 |
| 갱신 | 표본 주기와 같게 (현재 로그는 5초 표본) | 화면 갱신 주기를 따로 만들지 않는다 |
| 카드 클릭 | v2 작성 과정 팝업을 **그대로 재사용** | 같은 기록을 두 벌로 만들지 않는다 |
| 진행 중 이탈 표기 | `14:16:00 ~ 진행 중` / 이어 쓴 양은 "아직 안 돌아왔어요" | 끝나지 않은 일의 끝 시각을 지어내지 않는다 |
